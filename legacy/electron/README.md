# 🚀 Search Server for Roblox game

**Search Server for Roblox game** — это профессиональное приложение на базе Electron для поиска и фильтрации серверов в играх Roblox. Программа позволяет находить серверы с минимальным пингом или определенным количеством игроков, предоставляя прямую ссылку для быстрого подключения.

Этот проект является улучшенным форком оригинального инструмента [Job_Id_Builder](https://github.com/proopasip/Job_Id_Builder) от **Proopasip**, который был доработан и модернизирован пользователем **egefefefefef**.

---

## ✨ Основные возможности

- 🔍 **Умный поиск серверов**: Быстрый поиск публичных серверов по `PlaceId` или ссылке на игру.
- 📉 **Гибкая фильтрация**: 
    - Фильтр по максимальному пингу (найдите самый стабильный сервер).
    - Фильтр по минимальному количеству игроков.
- 🌐 **Полная интернационализация**: Поддержка 7 языков (Русский, Английский, Украинский, Китайский, Японский, Корейский, Итальянский).
- 🌓 **Современный интерфейс**: Поддержка темной и светлой тем оформления.
- ⚡ **Мгновенное подключение**: Генерация прямой ссылки для запуска игры на конкретном сервере.

---

## 🛠 Технологический стек

- **Framework**: [Electron](https://www.electronjs.org/)
- **Language**: JavaScript (ES6+)
- **API**: Roblox Games API
- **HTTP Client**: [Axios](https://axios-http.com/)
- **Styling**: CSS3 (Custom Properties / Variables)

## 📦 Инструкция по сборке (Build)

Для того чтобы собрать приложение в исполняемый файл (`.exe`), следуйте этим простым шагам:

### 1. Требования
Убедитесь, что у вас установлен [Node.js](https://nodejs.org/).

### 2. Сборка
В корне проекта находятся готовые скрипты для автоматизации процесса:

**Для Windows:**
Запустите файл `build.bat`. Он автоматически установит зависимости и соберет приложение.
```cmd
.\build.bat
```

**Для Linux/macOS:**
Запустите файл `build.sh`:
```bash
chmod +x build.sh
./build.sh
```

### 3. Где найти результат?
После завершения сборки готовый установщик и исполняемые файлы будут находиться в папке:
`dist/`
